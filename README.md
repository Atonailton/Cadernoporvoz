# Caderno Via Voz

Um caderno virtual que escreve conforme você fala. Ideal para estudantes que desejam anotar conteúdos por voz de forma simples e rápida. Com 500 páginas, capa personalizada, agenda na contra capa e reconhecimento de voz em tempo real.

## Funcionalidades

- Reconhecimento de voz (em português)
- Geração automática de linhas por página
- Cabeçalho com campos para:
  - Nome da escola
  - Data
  - Matéria (Matemática, Português ou Inglês)
- Navegação entre 500 páginas
- Agenda na contra capa
- Interface simples, funcional e responsiva

## Como usar

1. Clone ou baixe o projeto.
2. Abra o arquivo `index.html` em seu navegador.
3. Use os botões para navegar entre as páginas.
4. Clique em **"Falar"** e comece a ditar o conteúdo da aula.

## Como publicar no Vercel

1. Acesse [https://vercel.com](https://vercel.com).
2. Crie um novo projeto e envie o arquivo `index.html`.
3. Pronto! Seu caderno estará online.

## Requisitos

- Navegador compatível com reconhecimento de voz (`webkitSpeechRecognition`)
  - Recomendado: Google Chrome
